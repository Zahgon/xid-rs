Port of Go’s crypto/sha256 (the New/Write/Sum trio only).

readMachineID hashes the platform machine id (or hostname) and keeps the first three bytes of the digest, so the digest must match Go’s byte for byte. This is a straightforward FIPS 180-4 implementation; it is only ever fed a hostname-sized input.
