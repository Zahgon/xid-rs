Port of Go’s unexported readMachineIDFromEnv.

Returns None where Go returns a nil slice. Exposed (Go keeps it package-private) so the ported test-suite can exercise it exactly like the in-package Go test does.

§Panics

With "XID_MACHINE_ID value is set to not a number" when XID_MACHINE_ID does not parse as an integer, and with "XID_MACHINE_ID out of range for 3 bytes" when it does not fit in three bytes — the same two messages, and the same conditions, as Go.
